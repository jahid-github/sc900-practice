Their correct answers are visible, but the complete option lists are not. Reconstructed or added practice options are explicitly noted on those questions.

Scoring: one point per fully correct question; no partial credit. Multiple-answer questions require exactly the correct set. Matching, dropdown, and Yes/No questions require every part to be correct. Skipped or incomplete questions receive zero on submission. Checking an answer locks it for this attempt. Start again to reset.

To expand: open this HTML file in a text editor, find QUESTION BANK, and append an object with a unique serial id. Supported types: single, multiple, matching, dropdown, yesno, and sentence. Keep IDs in serial order. Options and answers use text strings. Each object has explanation (paragraph array) and references (title/path pairs). Copy an existing question of the same type as a template. Increase BANK_VERSION after changing existing questions to start a fresh saved session.

Answers are stored in this browser when storage is available. Moving the file or changing browsers may start a new session. The quiz works offline; reference links require internet access. No accounts, external libraries, or network requests are needed to take the quiz.
